# Spring Boot 4.1 e Java 21

Este exemplo adota Spring Boot 4.1.0 com Java 21 (LTS) para alinhar com a versão estável mais recente no momento da criação. A stack modular do Spring Boot 4 (starters separados, SpringDoc 3.x) exige dependências explícitas que não existiam no Boot 3 — registrar essa escolha evita downgrade acidental por compatibilidade percebida.
